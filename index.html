Security is notan add-on.

Cyber security, UMaT

With a background in cyber security, every system I build ships with these protections from day one. You never have to ask for them.

  1. 01

    Encrypted connections

    HTTPS everywhere, so data moving between your users and your system cannot be read or changed.

  2. 02

    Protected passwords

    Passwords are hashed and never stored as plain text, so a leak does not expose your users.

  3. 03

    Attack-proof forms

    Every form and input is checked to block SQL injection, cross site scripting and forged requests.

  4. 04

    Login defence

    Rate limits and lockouts stop people guessing passwords, with two-step login where it matters.

  5. 05

    Right access, right people

    Staff only see and change what their job needs, nothing more.

  6. 06

    Flood protection

    Fake traffic meant to knock your site offline (DDoS) is filtered out before it reaches you.

  7. 07

    Secure sessions

    Logins expire, cookies are locked down and accounts can be signed out everywhere at once.

  8. 08

    Safe file uploads

    Every upload is checked for type and size, and stored where it can never run as code.

  9. 09

    Secrets kept secret

    API keys and passwords never live in the code or anywhere the public can see.

  10. 10

    Security headers

    Browser rules that block clickjacking, injected scripts and other common tricks.

  11. 11

    Always up to date

    Frameworks and packages are patched as soon as security fixes are released.

  12. 12

    Private by default

    Only the data that is needed is collected, and personal details are removed when an account is deleted.

  13. 13

    Secure payments

    Payments are confirmed with the provider directly, prices come from the server and nothing is charged twice.

  14. 14

    Activity logs

    A clear record of who changed what and when, so nothing important happens unseen.

  15. 15

    Backups and monitoring

    Regular tested backups and uptime checks, so problems are caught early and data can be restored.

  16. 16

    Checked before launch

    Every project goes through a security review before it goes live, not after something goes wrong.

And that is only the start. Every system gets the protection its data needs.
